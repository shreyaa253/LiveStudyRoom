# 📌 Overview

The **Real-Time Academic Space Monitoring System** is an intelligent web-based platform developed to monitor, manage, and optimize the utilization of academic spaces such as classrooms, laboratories, seminar halls, and study areas within educational institutions.

This system provides **live occupancy tracking**, **availability status**, and **space analytics** to improve operational efficiency, reduce scheduling conflicts, and enhance the overall campus management experience.

Built with scalability and automation in mind, the platform bridges the gap between traditional academic management systems and modern smart-campus solutions.

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/yourusername/real-time-academic-space-monitoring-system.git
```

## 2️⃣ Navigate to the Project Directory

```bash
cd real-time-academic-space-monitoring-system
```

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

## 4️⃣ Run the Server

```bash
python manage.py runserver
```

## 5️⃣ Open in Browser

```bash
http://127.0.0.1:8000/
```
